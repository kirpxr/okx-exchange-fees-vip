## 歐易交易所是什麼？

歐易交易所是一個中心化加密貨幣交易平台，英文名稱為 OKX。它的主要用途是讓使用者在同一個帳戶中進行數位資產買賣、管理資產，以及使用部分衍生品和鏈上工具。

對一般使用者來說，最常接觸的是以下幾個區域：

- **現貨交易**：直接買入或賣出 BTC、ETH、SOL、USDT 等數位資產。
- **閃兌**：以較簡化的方式將一種資產兌換成另一種資產。
- **合約交易**：包括永續合約和交割合約，通常涉及槓桿與保證金。
- **跟單交易**：選擇交易員後，按照設定自動複製部分交易。
- **策略交易**：使用網格、定投或其他自動化交易策略。
- **賺幣與質押**：將部分資產放入符合條件的產品中，獲取平台顯示的收益。
- **Web3 錢包與 DEX**：管理鏈上資產、進行跨鏈或去中心化交易。

官方目前將現貨、合約、TradFi、DEX、事件合約、閃兌、策略交易和跟單交易等放在交易服務架構內；功能是否對你的所在地開放，則需要登入帳戶後確認。

這裡有一個容易混淆的地方：**交易所的「VIP 等級」不是月費會員，也不是購買某個固定套餐。** 它主要根據近 30 天交易量、資產持有量，以及不同產品的交易活動來判定。等級每天更新，達到條件後通常由系統自動調整。

## 歐易交易所手續費怎麼算？

OKX 的交易手續費主要分為：

- **掛單手續費 Maker**：委託進入訂單簿，等待市場撮合。
- **吃單手續費 Taker**：直接與訂單簿中已有的委託成交。
- **現貨或槓桿交易費**：通常按照成交數量及適用費率計算。
- **合約交易費**：按照合約成交額及帳戶費率等級計算。
- **資金費**：永續合約持倉可能產生，並不等同於交易手續費。
- **提幣、支付及法幣相關費用**：依資產、網路、支付方式及所在地區規則另行計算。

官方說明，掛單通常比吃單費率低，因為掛單為訂單簿提供流動性；但實際費率要以你的帳戶、交易產品和交易對頁面顯示為準。費率等級不是即時更新，而是每日先進行資產和交易量快照，再於指定時間更新。

## OKX 有哪些主要交易功能？

### 現貨交易

現貨交易是大多數新手的起點。你實際買入的是相應數位資產，沒有合約到期日，也不會因為槓桿倍數而放大倉位。

常見操作包括：

1. 選擇交易對，例如 BTC/USDT。
2. 選擇限價單或市價單。
3. 輸入價格和數量。
4. 確認預估成交金額與手續費。
5. 下單後查看委託或成交紀錄。

限價單可以控制價格，但不一定馬上成交；市價單成交速度通常較快，但最終成交價格可能因市場深度和滑點而變動。

### 閃兌

閃兌適合希望快速完成資產轉換、又不想研究訂單簿的人。這種方式通常會直接顯示報價，但報價中可能已經反映價差。官方手續費說明也提醒，買賣或 Convert 類流程可能以單一報價呈現成本，不一定像訂單簿交易一樣單獨列出 Maker 或 Taker 費用。

因此，閃兌介面看起來簡單，不代表成本永遠最低。大額兌換前，可以將閃兌報價和現貨訂單簿的預估成交結果比較一下。

### 合約交易

OKX 提供永續和交割合約。合約可以用較少保證金建立較大名義價值的倉位，但這也會放大損益。

需要特別留意：

- 槓桿越高，價格波動對保證金的影響越大。
- 永續合約可能產生資金費。
- 強平價格會受保證金、槓桿、倉位大小和市場價格影響。
- 強制平倉時可能按照當前帳戶費率收取相關費用。
- 平台顯示的預估強平價格不代表實際市場一定能以該價格成交。

如果只是想買入 BTC 或 ETH，沒有必要因為看到合約按鈕就使用合約。交易工具越多，並不等於每個人都需要使用全部工具。

### 跟單與策略交易

跟單交易可以讓使用者選擇交易員，依照設定複製其部分交易。策略交易則通常用於網格、定投或其他預先設定的交易邏輯。

這類功能降低了操作門檻，但不會消除市場風險。跟單前至少要查看：

- 交易員的歷史報酬和最大回撤。
- 使用的是現貨跟單還是合約跟單。
- 是否設有單筆和總額限制。
- 跟單資金是否能隨時停止。
- 收益分成、手續費和風控設定。

官方資料指出，現貨跟單沒有合約爆倉風險，但現貨資產仍可能因市場下跌而減值；低風險不等於沒有風險。
